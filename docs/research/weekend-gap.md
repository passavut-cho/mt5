# Weekend gap ของ XAUUSD 2018–2022 (T-042)

> ข้อมูลประกอบ O2 ของ S-B (`spec-donchian-h4.md`) — **วัดราคาอย่างเดียว ไม่ใช่ backtest กลยุทธ์ (ไม่นับเป็น look)**

## วิธีวัด
- script `src/Scripts/WeekendGapDump.mq5` รันแบบ startup script (`tests/tester-ini/weekend_gap_startup.ini`, XAUUSD H4, IC demo history) → `data/research/weekend_gaps_2018_2022.csv`
- gap = open ของแท่ง H4 แรกหลังแท่งศุกร์สุดท้าย − close ของแท่ง H4 สุดท้ายวันศุกร์ (server time; แท่งศุกร์สุดท้ายคือ 20:00)
- ATR(14,H4) = SMA ของ true range 14 แท่ง ณ แท่งศุกร์สุดท้าย (นิยามเดียวกับ `iATR`)
- สถิติ: `python tests/python/weekend_gap_stats.py`

## ข้อสังเกต / ข้อจำกัด
- 253 สัปดาห์ ไม่ใช่ 261 เต็ม: สัปดาห์ที่ไม่มีแท่งศุกร์ (วันหยุด/ตลาดปิด) หรือมี ATR ไม่ครบไม่ถูกนับ — ไม่ได้ตรวจแยกรายสัปดาห์ว่าขาดเพราะอะไร
- gap สูงสุดเมื่อวัดเป็น ATR คือ ~1.6× และไม่มีสัปดาห์ใดเกิน 2× ในช่วงนี้ → ไม้ที่ถือข้ามสุดสัปดาห์มีความเสี่ยง gap ผ่าน SL ได้ราว ≤1.6 ATR (ใน 5 ปี) • ขนาดเป็น $ ต่อ lot ขึ้นกับ ATR ณ ตอนนั้น (gap 2022-02-25 = $32 ≈ $3,234/lot)
- **ไม่ได้กำหนดค่า `InpWeekendLockATR`** — เป็นการตัดสินใจของ Cowork/Owner ที่จะเติมในหัวข้อ "O2 final" ของ spec (T-045 จะ BLOCKED จนกว่าจะมีตัวเลข)
